# Album Rating Program

A Python program that allows users to rate albums and receive a recommendation based on their rating.

## Features

- Enter an album title and artist
- Rate an album from 1–10
- Validates user input to ensure ratings are within the correct range
- Provides a recommendation based on the album rating
- Displays an album rating summary

## Technologies Used

- Python

## What I Learned

This project helped me practice Python fundamentals including functions, conditional statements, loops, user input, exception handling, and input validation.

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Run:

```bash
python albumRatings.py
